## 🚀 Featured Projects

<details>
<summary><b>🤖 SMM Panel Bot by Shuvo MK</b> — Production Telegram SMM Automation</summary>

<br/>

> A full-featured Telegram bot for Social Media Marketing panels, game topups, and Telegram services.

**Architecture Overview**

```
smm-panel-bot-by-Shuvo-mk/
├── bot.py                    # Entry point, dispatcher setup
├── handlers/
│   ├── user.py               # User flows, balance, orders
│   ├── admin.py              # Admin panel, broadcasts
│   └── topup.py              # Game topup (FF, MLBB, PUBG)
├── keyboards/
│   ├── reply.py              # ReplyKeyboardMarkup with style dict
│   └── inline.py             # InlineKeyboardMarkup flows
├── utils/
│   └── order_logger.py       # Structured order logging
└── config.py                 # Environment variables
```

| Attribute | Detail |
|-----------|--------|
| **Stack** | Python, python-telegram-bot v21, MongoDB Atlas |
| **APIs** | SMMFM API, FlashTopup API |
| **Deployment** | Railway (cloud) |
| **Database** | MongoDB Atlas (persistent, cloud) |
| **Services** | SMM orders, Game topup, Telegram services |
| **UI** | Dict-based colored button system (primary/success/danger) |
| **Security** | Admin-only handlers, user_data isolation |
| **Scalability** | Async handlers, MongoDB indexing |

**Key Features**
- 🎮 Game topup: Free Fire, Mobile Legends, PUBG Mobile
- 📱 SMM service ordering with real-time status
- 💰 Balance management with Taka/USD support
- 👑 Full admin panel with broadcast, user management
- 📊 Structured order logging with timestamps
- 🔒 Secure user session handling

**Lessons Learned**
- Railway's ephemeral filesystem requires external DB (MongoDB Atlas)
- `user_data` must be cleared on handler exit to prevent state leaks
- Webhook/polling conflict requires clean process management in Termux

</details>
